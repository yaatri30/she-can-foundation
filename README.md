# she-can-foundation
A premium, modern, fully responsive NGO website built using **HTML, CSS, and JavaScript**.
Designed with a clean and elegant UI

## Features Included
- Full-screen Hero Section
- Sticky Glassmorphism Navbar
- Dark / Light Mode Toggle
- Animated Counters
- Responsive Gallery Grid
- Programs & Initiatives Section
- Testimonials Section
- Contact Form UI
- Beautiful CTA Section
- Footer with Social Links
- Back-to-Top Button
- Mobile Responsive Design
- Preloader Animation

# Built With
- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Font Awesome Icons
- Google Fonts (Inter)

#Color Palette:

Includes a fully functional dark/light mode toggle with local storage support.
User preference is automatically remembered.

# Performance Features
